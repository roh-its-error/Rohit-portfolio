ROHIT SAWIAYA - PERSONAL PORTFOLIO

Files:
- index.html: Website content and sections
- style.css: Black and blue responsive design

HOW TO OPEN:
1. Extract the ZIP file.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html to open it in your browser.

BEFORE SUBMISSION:
1. Confirm the email address shown in index.html is correct.
2. Replace the GitHub and LinkedIn links with your profile URLs.
3. To add your photo, put an image named profile.jpg in this folder.
   In index.html, find the profile-placeholder div and replace it with:
   <img class="profile-photo" src="profile.jpg" alt="Rohit Sawiaya">
4. Check that all details are correct and add any other projects you have completed.
